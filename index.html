Search Metric Analyzer

A multi-agent system that automates the hardest parts of search metric investigation.

When a search quality metric drops, finding the root cause is genuinely hard. It crosses multiple sub-systems, requires decomposition across enterprise segments, and needs recognition of co-movement patterns that distinguish real regressions from noise. An experienced engineer can spend days on a single investigation.

This system automates the structured legwork through a four-stage pipeline, built with 706 tests across 13 synthetic scenarios, using only PyYAML and pytest as dependencies.

How it works

  • Decompose — Kitagawa-Oaxaca decomposition isolates which segments drove the movement
  • Detect — Step-change detection and co-movement pattern matching across metrics
  • Diagnose — Pattern archetype recognition with confidence scoring
  • Format — Structured report with hypothesis evaluation and next steps
