From question to operating system

That end-to-end loop is the common thread across product analytics, customer measurement, search relevance, and AI systems. The deliverable is not a notebook; it is a decision capability that other people can use.

Selected work

Search Metric Analyzer

A public multi-agent system for turning search metric movement into structured diagnosis.

Search quality shifts rarely have one obvious cause. The evidence sits across segments, metrics, ranking behavior, and product context. Search Metric Analyzer organizes that investigation into an inspectable workflow so an analyst can move from change detection to a ranked set of hypotheses and next steps.

I built the project independently to make the full system visible: deterministic analysis where correctness matters, specialist agents where interpretation helps, and a product surface that keeps evidence attached to conclusions.

How it works

  1. Decompose — isolate which segments drove the movement.
  2. Detect — compare step changes and co-movement across metrics.
  3. Diagnose — evaluate competing patterns with explicit confidence.
  4. Report — produce a structured investigation with next actions.
